# TIJPrinter1C — описание API

Внешняя компонента (Native API) для 1С:Предприятие 8.3. Управляет принтером TIJ по сети
и заполняет поля печатного сообщения данными из 1С.

Версия компоненты: **1.2.0.0**

## 1. Что умеет

- подключение к принтеру по TCP и контроль состояния подключения;
- запуск и остановка печати;
- очистка буфера принтера;
- отправка данных в поля печатного сообщения (в том числе в 2D-код),
  по одному полю или всеми полями этикетки одной командой;
- отправка этикеток пачкой с автоматическим контролем очереди принтера;
- запрос числа сообщений в очереди и запрет вытеснения старой записи;
- расшифровка кодов ответа принтера;
- чтение текста последней ошибки.

Компонента не управляет механикой принтера и не заменяет настройку сообщения на самом
принтере. Сообщение, шрифты, положение полей, тип кода и его параметры настраиваются
на принтере, компонента только передаёт данные и команды.

## 2. Состав и имена

| Что | Значение |
|---|---|
| Библиотека x64 | `TIJPrinter1C_x64.dll` |
| Библиотека x86 | `TIJPrinter1C_x86.dll` |
| Имя компоненты при подключении | задаётся программистом, в примерах `TIJ` |
| Имя объекта компоненты | `TIJPrinter` |
| Полное имя объекта в коде | `AddIn.<ИмяКомпоненты>.TIJPrinter` |
| Идентификатор для БСП | `TIJPrinter` (из `INFO.XML`, атрибут `progid` без префикса `AddIn.`) |
| Наименование в карточке БСП | `Принтер линии TIJ` |

Объект в коде создаётся один раз и живёт до закрытия сессии. Все вызовы идут через него.

## 3. Методы

Русское и латинское имя равнозначны, платформа принимает любое из них.

| Русское имя | Латинское имя | Параметры | Возврат |
|---|---|---|---|
| `Подключить` | `Connect` | `IP-адрес` (Строка), `Порт` (Число, необязательно) | Булево |
| `Отключить` | `Disconnect` | — | Булево |
| `ЕстьПодключение` | `IsConnected` | — | Булево |
| `НачатьПечать` | `StartPrint` | — | Число |
| `ОстановитьПечать` | `StopPrint` | — | Число |
| `ОчиститьБуфер` | `ClearBuffer` | — | Число |
| `ОтправитьПоле` | `SendField` | `ID поля` (Число), `Значение` (Строка) | Число |
| `НачатьПакет` | `BeginPackage` | — | Булево |
| `ДобавитьПоле` | `AddField` | `ID поля` (Число), `Значение` (Строка) | Число |
| `ОтправитьПоля` | `SendPackage` | — | Число |
| `ОтправитьЭтикетку` | `SendLabel` | `Глубина очереди` (Число), `Таймаут ожидания, мс` (Число) | Число |
| `ЗанятоВБуфере` | `GetBufferUsed` | — | Число |
| `УстановитьОтказПриПереполнении` | `SetRejectOnBufferFull` | `Отклонять` (Булево) | Число |
| `ПолучитьОшибку` | `GetLastError` | — | Строка |
| `ОписаниеКода` | `DescribeCode` | `Код` (Число) | Строка |
| `УстановитьКодировку` | `SetEncoding` | `Кодировка` (Число) | Булево |

### Подключить(IP-адрес, Порт = 8010)

Открывает TCP-соединение с принтером. Порт можно не указывать, по умолчанию 8010.
Повторный вызов сначала закрывает предыдущее соединение.

- таймаут отправки и приёма данных: 5 секунд;
- ожидание ответа принтера на команду: 2 секунды;
- допустимый порт: 1..65535, выход за диапазон отменяет вызов.

Возвращает `Истина`, если соединение установлено.

### Отключить()

Закрывает соединение. Возвращает `Истина`. Повторный вызов безопасен.

### ЕстьПодключение()

Возвращает текущее состояние. При ошибке обмена (обрыв, таймаут отправки) состояние
сбрасывается в `Ложь`, и перед следующей командой нужно подключиться заново.

### НачатьПечать(), ОстановитьПечать(), ОчиститьБуфер()

Отправляют команду `11`, `12` и `21` протокола соответственно. Возвращают код ответа
принтера (см. раздел 4).

`ОчиститьБуфер` освобождает очередь данных, но не останавливает уже начатую печать.

### ОтправитьПоле(ID поля, Значение)

Отправляет значение в поле печатного сообщения, команда `1D` протокола.
Именно так заполняются и текстовые поля, и 2D-код, если у него источник данных
настроен как данные по номеру.

- `ID поля`: 0..255, передаётся одним байтом. Значение должно совпадать с настройкой
  поля на принтере (ID поля или Данные ID).
- `Значение`: строка, передаётся в UTF-8. Длина ограничена 255 байтами.

Одна команда это одно поле и одно место в буфере принтера.

### НачатьПакет(), ДобавитьПоле(ID поля, Значение), ОтправитьПоля()

Позволяют заполнить все поля этикетки одной командой. Это важно из-за буфера принтера:
каждая отдельная отправка занимает отдельное место в буфере, а одна команда с несколькими
полями занимает одно место.

```bsl
Принтер.НачатьПакет();                    // очистить пакет
Принтер.ДобавитьПоле(0, "27.04.2019");    // текстовое поле
Принтер.ДобавитьПоле(1, "01088099...");   // 2D-код
Статус = Принтер.ОтправитьПоля();         // оба поля уходят одним кадром
```

- `НачатьПакет` очищает накопленное и возвращает `Истина`.
- `ДобавитьПоле` проверяет номер поля и значение и складывает поле в пакет.
  Возвращает `0`, если поле принято, и `-3`, если параметры неверны.
  Повторный вызов с тем же номером заменяет значение.
- `ОтправитьПоля` отправляет все накопленные поля одним кадром и очищает пакет
  независимо от результата. Пустой пакет вернёт `-3`.

### ОтправитьЭтикетку(Глубина очереди, Таймаут ожидания, мс)

Отправляет накопленный пакет, но сначала проверяет очередь принтера и при необходимости
ждёт, пока в ней освободится место. Именно этот метод нужен для печати пачкой: программа
не подбирает паузы вручную и не следит за кодом `67`.

- `Глубина очереди` — сколько сообщений разрешено держать в буфере принтера. Пока занято
  меньше, отправка идёт сразу. Ноль значит не проверять очередь и отправить немедленно.
- `Таймаут ожидания, мс` — сколько всего ждать освобождения места. Ноль значит взять
  умолчание, 60 секунд.

Возвращает код ответа принтера, `-4` если место не освободилось за отведённое время,
или `-3` если пакет пуст. При `-4` пакет сохраняется, его можно отправить повторно
с той же или с большей глубиной.

### ЗанятоВБуфере()

Возвращает число сообщений, которые сейчас лежат в очереди принтера. Отрицательное
значение это код ошибки. Полезно для журнала и для контроля темпа при ручной отладке.

### УстановитьОтказПриПереполнении(Отклонять)

Управляет поведением принтера при заполненной очереди: `Истина` значит отклонять новую
команду, `Ложь` значит принимать её с вытеснением самой старой записи.

Для печати кодов маркировки правильное значение — `Истина`. При вытеснении на этикетку
попадёт код из предыдущей этикетки, и это будет брак, который заметят не сразу.

Настройка хранится в принтере, поэтому достаточно выставить её один раз при запуске
смены. Заодно выставлять не нужно.

### ПолучитьОшибку()

Возвращает текст последнего неудачного вызова. Пустая строка означает, что ошибок не было.
Вызывать имеет смысл после возврата `-1`, `-2`, `-3` или `-4`. Текст очищается в начале
каждой команды, поэтому он всегда относится к последнему вызову.

### ОписаниеКода(Код)

Возвращает расшифровку кода, который вернул любой метод. Полезна для журнала и для вывода
понятного сообщения оператору.

```bsl
Статус = Принтер.ОстановитьПечать();
Сообщить("ОстановитьПечать: " + Принтер.ОписаниеКода(Статус));
// например: P_Status=0x12 (18): печать не запущена
```

### УстановитьКодировку(Кодировка)

Задаёт кодировку, в которой значения уходят в принтер. Должна совпадать с кодировщиком поля
на принтере.

| Кодировка | Что это | Для каких полей |
|---|---|---|
| `0` | UTF-8, по умолчанию | поля с кодировщиком ASCII, латиница и цифры |
| `1` | UTF-16LE | поля с кодировщиком Unicode, кириллица |

Некорректное значение вернёт `Ложь`, режим останется прежним.

Режим Unicode требует проверки на конкретном принтере: кодировщик поля и порядок байтов
должны совпасть. Проверяйте на реальной печати.

## 4. Возвращаемые значения команд

| Возврат | Что значит | Что делать |
|---|---|---|
| `0` и больше | принтер ответил подтверждением, число это статус принтера `P_Status` | `0` значит «без ошибок», иное значение смотреть в таблице 4.1 |
| `-1` | ответа нет: таймаут 2 секунды, обрыв или нераспознанный кадр | смотреть `ПолучитьОшибку()`, проверить связь с принтером |
| `-2` | принтер ответил отказом (NAK) | причина в `ПолучитьОшибку()`, разбор в таблице 4.2 |
| `-3` | параметры неверны, команда принтеру не отправлялась | текст ошибки говорит, что именно не так |
| `-4` | очередь принтера полна, свободного места не появилось за отведённое время | пакет сохранён, повторить отправку позже или увеличить глубину очереди |

Важно: `-1`, `-2`, `-3` и `-4` это коды компоненты, а не принтера. Причина всегда лежит
в тексте `ПолучитьОшибку()`. Любой код можно расшифровать методом `ОписаниеКода`.

### 4.1 Статус принтера P_Status (ответ подтверждением)

Числа выводятся в десятичном виде, в протоколе они записаны шестнадцатеричными.

| Код | В выводе | Значение |
|---|---|---|
| `00` | 0 | без ошибок |
| `01` | 1 | есть ошибки принтера |
| `0E` | 14 | в команде меньше полей, чем в сообщении |
| `11` | 17 | печать уже запущена |
| `12` | 18 | печать не запущена |
| `14` | 20 | интервал печати меньше минимально допустимого |
| `42` | 66 | команда заняла последнее свободное место в буфере |
| `43` | 67 | буфер был полон |
| `FF` | 255 | принтер заблокирован |

Полный список приведён в разделе 4.2.1 протокола принтера.

### 4.2 Статус команды C_Status (ответ отказом)

Приходит только вместе с `-2`, попадает в текст ошибки в виде `NAK, C_Status=N`.
`N` выводится десятичным, в протоколе коды шестнадцатеричные.

| Код | В выводе | Значение |
|---|---|---|
| `06` | 6 | начало команды не `1B 02` |
| `07` | 7 | конец команды не `1B 03` |
| `08` | 8 | неверная контрольная сумма |
| `09` | 9 | число полей равно нулю |
| `0A` | 10 | неизвестный тип модуля |
| `11` | 17 | неизвестный идентификатор команды |
| `3C` | 60 | неверный режим печати |

## 5. Порядок работы

### 5.1 Одна этикетка

Все поля этикетки отправляются одной командой, поэтому используется пакет:

```
Подключить
  ОчиститьБуфер
  НачатьПакет
  ДобавитьПоле         (для каждого поля этикетки)
  ОтправитьПоля        (все поля уходят одним кадром, одно место в буфере)
  НачатьПечать
Отключить
```

Если поле на этикетке одно, можно пользоваться `ОтправитьПоле`.

### 5.2 Буфер принтера

Буфер принтера хранит от 1 до 10 команд отправки данных. Каждая команда `ОтправитьПоле`
занимает одно место, каждая напечатанная этикетка освобождает одно место.

```
отправили данные        -> буфер плюс один
напечаталась этикетка   -> буфер минус один
```

Отсюда правила:

- если на этикетке несколько полей, отправляйте их одной командой через пакет:
  одна команда занимает одно место, независимо от числа полей в ней. Отправка
  полей по одному увеличивает очередь на каждую этикетку, и буфер переполняется
  в несколько раз быстрее;
- данные под следующую этикетку нужно отправлять только после того, как
  освободилось место;
- `66` в ответе значит, что команда заняла последнее свободное место, данные приняты;
- `67` в ответе значит, что буфер был полон: в зависимости от настройки принтера
  новая команда либо отклонена, либо вытеснила самую старую. В обоих случаях
  отправленные данные на этикетку не попадут;
- перед новым циклом отправки надёжнее вызвать `ОчиститьБуфер`, чтобы в очереди
  не оставались значения от предыдущих отправок.

Есть и вторая ловушка, про которую легко забыть. Если очередь опустеет, а датчик
сработает, принтер напечатает последнее сообщение повторно. То есть очередь нужно
держать непустой и при этом не переполнять. Рабочий диапазон примерно от 3 до 8
сообщений, точное число зависит от скорости линии и от скорости 1С.

### 5.3 Печать пачкой

Ручной контроль очереди не нужен: метод `ОтправитьЭтикетку` сам проверяет занятость
буфера командой `33` и ждёт, пока освободится место. Программа просто перебирает коды
в цикле, а глубину очереди задаёт один раз.

```
Подключить
  ОчиститьБуфер
  УстановитьОтказПриПереполнении(Истина)   один раз за смену
  для каждого кода:
      НачатьПакет
      ДобавитьПоле                          для каждого поля этикетки
      ОтправитьЭтикетку(8, 60000)           ждёт место и отправляет
Отключить
```

Очередь заполняется до указанной глубины и дальше держится на этом уровне, пока линия
печатает. Как только принтер забирает сообщение, компонента отправляет следующее.

## 6. Кадр обмена

Компонента собирает кадр сама, знать его устройство нужно только для диагностики.

```
1B 02 <адрес> <команда> <данные...> 1B 03 <контрольная сумма>
```

| Элемент | Значение |
|---|---|
| начало кадра | `1B 02` |
| адрес принтера | `00` |
| контрольная сумма | сумма всех байтов кадра, включая начальные и конечные, от 256 |
| команда `11` | начало печати |
| команда `12` | остановка печати |
| команда `1D` | данные поля |
| команда `21` | очистка буфера |
| ответ подтверждением | `1B 06 <адрес> <статус> ...` |
| ответ отказом | `1B 15 <адрес> <код отказа> ...` |

## 7. Кодировка и длины

- По умолчанию строки из 1С передаются в UTF-8. Это подходит полям с кодировщиком ASCII:
  латиница, цифры, знаки. Для кириллицы метод `УстановитьКодировку(1)` переключает
  передачу в UTF-16LE, а поле на принтере должно быть переведено в режим Unicode.
- `ID поля` ограничен диапазоном 0..255.
- Длина значения ограничена 255 байтами. Если строка длиннее, метод вернёт `-3`
  и на принтер ничего не уйдёт. В режиме Unicode лимит считается в байтах, то есть
  кириллическая строка занимает вдвое больше места.
- Пустое значение недопустимо: протокол требует минимум один байт, метод вернёт `-3`.
- Адрес принтера зашит как `00`.

## 8. Примеры на 1С

### 8.1 Подключение из файла

Подходит для толстого клиента и файловой базы.

```bsl
ПутьКФайлу = "C:\TIJ\TIJPrinter1C_x64.dll";
Если Не ПодключитьВнешнююКомпоненту(ПутьКФайлу, "TIJ", ТипВнешнейКомпоненты.Native) Тогда
    Сообщить("Не удалось подключить компоненту");
    Возврат;
КонецЕсли;

Принтер = Новый("AddIn.TIJ.TIJPrinter");
```

### 8.2 Подключение через справочник «Внешние компоненты» (БСП)

Нужно для тонкого клиента, веб-клиента и работы с нескольких машин: библиотека хранится
в информационной базе, а не на диске.

```bsl
Результат = ВнешниеКомпонентыСервер.ПодключитьКомпоненту("TIJPrinter");
Если Не Результат.Подключено Тогда
    Сообщить("Не удалось подключить компоненту");
    Возврат;
КонецЕсли;

Принтер = Результат.ПодключаемыйМодуль;
```

`"TIJPrinter"` это идентификатор из карточки, он берётся из `INFO.XML`.

### 8.3 Печать одной этикетки

```bsl
Если Не Принтер.Подключить("192.168.1.50", 8010) Тогда
    Сообщить("Принтер недоступен: " + Принтер.ПолучитьОшибку());
    Возврат;
КонецЕсли;

Принтер.ОчиститьБуфер();

Принтер.НачатьПакет();
Принтер.ДобавитьПоле(0, "27.04.2019");
Принтер.ДобавитьПоле(1, "0108809990845656215X56BK1234567");

Статус = Принтер.ОтправитьПоля();
Если Статус < 0 Тогда
    Сообщить("Данные не приняты: " + Принтер.ПолучитьОшибку());
    Принтер.Отключить();
    Возврат;
КонецЕсли;

Статус = Принтер.НачатьПечать();
Если Статус < 0 Тогда
    Сообщить("Печать не запущена: " + Принтер.ОписаниеКода(Статус));
КонецЕсли;

Принтер.Отключить();
```

Обратите внимание: два поля этикетки ушли одной командой, поэтому в буфере занято
одно место, а не два.

### 8.4 Печать пачкой кодов маркировки

Основной рабочий сценарий: перебрать коды из 1С и отдать их принтеру, не подбирая паузы.

```bsl
Если Не Принтер.Подключить("192.168.1.50", 8010) Тогда
    Сообщить("Принтер недоступен: " + Принтер.ПолучитьОшибку());
    Возврат;
КонецЕсли;

Принтер.ОчиститьБуфер();

// один раз за смену: при переполнении принтер отклонит команду,
// а не вытеснит чужой КИЗ
Принтер.УстановитьОтказПриПереполнении(Истина);

ГлубинаОчереди = 8;        // сколько этикеток держим в очереди принтера
ДатаСтрока     = Формат(ТекущаяДата(), "ДФ=dd.MM.yyyy");

Для Каждого КИЗ Из КодыМаркировки Цикл

    Принтер.НачатьПакет();
    Принтер.ДобавитьПоле(0, ДатаСтрока);
    Принтер.ДобавитьПоле(1, КИЗ);

    Статус = Принтер.ОтправитьЭтикетку(ГлубинаОчереди, 60000);

    Если Статус < 0 Тогда
        ЗаписьЖурналаРегистрации("Печать КИЗ", УровеньЖурналаРегистрации.Ошибка, , ,
            КИЗ + ": " + Принтер.ПолучитьОшибку());
        Прервать;
    КонецЕсли;

КонецЦикла;

Сообщить("В очереди принтера осталось: " + Принтер.ЗанятоВБуфере());
Принтер.Отключить();
```

Что здесь важно:

- `ОтправитьЭтикетку` возвращает `-4`, если место в очереди не освободилось за минуту.
  Пакет при этом не теряется, его можно отправить повторно.
- Ответ `66` это норма: он значит, что команда заняла последнее свободное место.
- Если в ответе пришёл `67`, значит защита от переполнения не выставлена или очередь
  была заполнена до запуска. Компонента такие команды не повторяет, код вернётся
  вызывающему.
- `ЗанятоВБуфере` после цикла покажет, сколько этикеток ещё ждёт печати. Если линия
  остановилась, там останется хвост, который напечатается по датчику.

### 8.6 Полезные замечания по данным

- Код маркировки передаётся строкой без скобок. Скобки вокруг идентификаторов это только
  человекочитаемое представление, в символ они не входят.
- Если в коде должен быть разделитель групп данных, он передаётся как `Символ(29)`.
- Перед отправкой длинной строки убедитесь, что длина поля на принтере не меньше длины
  строки, иначе принтер обрежет данные.

## 9. Упаковка архива для загрузки в базу

Компонента ставится в базу одним ZIP-архивом, формат строго ZIP.

Содержимое архива, файлы лежат в корне, без вложенных папок:

```
MANIFEST.XML              описание состава архива
INFO.XML                  сведения для карточки в справочнике
TIJPrinter1C_x64.dll      библиотека под 64-битную платформу
TIJPrinter1C_x86.dll      библиотека под 32-битную платформу, если собрана
```

Требования:

- имя файла `MANIFEST.XML` заглавными буквами, в корне архива;
- атрибут `path` каждой записи совпадает с именем файла в архиве;
- перечислить нужно только те библиотеки, файлы которых реально лежат в архиве;
- формат ZIP, архивы 7z или rar платформа не читает.

Сборка архива: `tools\pack.cmd` собирает библиотеки, раскладывает файлы и сам убирает
из манифеста записи, для которых нет файла. Проверка перед отправкой:

```
python tools/check_package.py <архив>.zip
```

Скрипт проверяет формат архива, расположение файлов, соответствие манифеста содержимому
и пригодность библиотек. Сообщение `ИТОГ: архив годен` означает, что архив можно отдавать.

## 10. Ограничения версии 1.2.0.0

| Ограничение | Подробности |
|---|---|
| Длина значения | до 255 байт. Строка длиннее не отправляется, метод возвращает `-3`, обрезки данных молча не происходит |
| Ёмкость очереди | задаётся настройкой самого принтера, обычно 10 сообщений. Компонента видит только занятость, изменить ёмкость из кода нельзя |
| Режим Unicode | реализован как UTF-16LE и требует проверки на конкретном принтере: должен совпасть кодировщик поля и порядок байтов |
| Только TCP | параметры последовательного порта не поддерживаются |
| Один принтер на объект | адрес принтера зашит как `00`, несколько принтеров в одном сообщении не поддерживаются |

Что изменилось по сравнению с 1.1.0.0:

- добавлена печать пачкой: `ОтправитьЭтикетку` сама проверяет занятость очереди
  (команда `33`) и ждёт свободного места, поэтому цикл в 1С не подбирает паузы;
- добавлен метод `ЗанятоВБуфере` для контроля очереди;
- добавлен метод `УстановитьОтказПриПереполнении` (команда `35`), он запрещает
  вытеснение старой записи и защищает от печати чужого кода;
- добавлен код `-4` для случая, когда место в очереди не освободилось за отведённое время.

Что изменилось по сравнению с 1.0.0.0:

- добавлена отправка всех полей этикетки одной командой (`НачатьПакет`, `ДобавитьПоле`,
  `ОтправитьПоля`), поэтому очередь в буфере больше не растёт на каждой этикетке;
- добавлен код `-3` и проверка длины значения: раньше строка длиннее 255 байт молча
  обрезалась, теперь команда не уходит и в `ПолучитьОшибку()` есть причина;
- текст ошибки очищается в начале каждой команды, добавлена расшифровка кодов
  (`ОписаниеКода`) и коды `C_Status` теперь выводятся в шестнадцатеричном и десятичном
  виде вместе с пояснением;
- добавлен метод `УстановитьКодировку` для полей с кодировщиком Unicode.

## 11. Быстрая диагностика

| Что видно | Причина | Что делать |
|---|---|---|
| `Подключить` вернул `Ложь` | нет сети, неверный адрес или порт, принтер занят | проверить адрес, порт 8010, доступность принтера |
| Команда вернула `-1` | таймаут 2 секунды или нераспознанный ответ | проверить связь, повторить, смотреть `ПолучитьОшибку()` |
| Команда вернула `-2`, в ошибке `C_Status=8` | неверная контрольная сумма | в актуальной версии исправлено, проверить, что подключена библиотека нужной сборки |
| Команда вернула `-2`, в ошибке `C_Status=17` | принтер не знает такую команду | проверить версию прошивки принтера |
| Команда вернула `-3` | неверные параметры: номер поля вне 0..255, пустое значение, значение длиннее 255 байт или пустой пакет | прочитать `ПолучитьОшибку()`, поправить данные. На принтер ничего не уходило |
| Команда вернула `-4` | очередь принтера полна и место не освободилось за отведённое время | проверить, идёт ли печать по датчику, поднять глубину очереди или увеличить таймаут. Пакет сохранён |
| В ответе `67` | буфер полон | дождаться печати, вызвать `ОчиститьБуфер` или перейти на `ОтправитьЭтикетку` |
| Напечаталась этикетка с чужим кодом | при переполнении включено вытеснение старой записи | вызвать `УстановитьОтказПриПереполнении(Истина)` |
| Одна и та же этикетка печатается повторно | очередь опустела, а датчик продолжает срабатывать | держать в очереди не меньше трёх этикеток |
| В ответе `17` | печать уже запущена | повторный запуск не нужен |
| В ответе `18` | печать не запущена | нормальный ответ на остановку |
| Данные не появляются в поле на принтере | не совпал ID поля или у поля не выбран источник «Протокол» | сверить ID, проверить настройку поля |
| Подключение из справочника возвращает `Ложь` | архив собран неверно | прогнать `check_package.py` |
