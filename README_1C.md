# TIJPrinter1C.dll — Внешняя компонента для 1С

## Подключение в 1С

```bsl
// Загрузка компоненты
ПутьКФайлу = "C:\TIJPrinter1C.dll";
ПодключитьВнешнююКомпоненту(ПутьКФайлу, "TIJ", ТипВнешнейКомпоненты.Native);
Принтер = Новый("AddIn.TIJ.TIJPrinter");
```

## Методы

### Connect(Адрес, Порт) → Булево
Подключение к принтеру по TCP.
```bsl
Результат = Принтер.Connect("10.10.0.2", 8010);
Если Не Результат Тогда
    Сообщить("Ошибка подключения: " + Принтер.GetLastError());
КонецЕсли;
```

### Disconnect() → Булево
Отключение от принтера.
```bsl
Принтер.Disconnect();
```

### IsConnected() → Булево
Проверка активного соединения.
```bsl
Если Принтер.IsConnected() Тогда
    // работаем
КонецЕсли;
```

### StartPrint() → Число
Запуск печати. Возвращает P_Status (0 = OK).
```bsl
Статус = Принтер.StartPrint();
Если Статус <> 0 Тогда
    Сообщить("Ошибка старта: " + Статус);
КонецЕсли;
```

### StopPrint() → Число
Остановка печати.
```bsl
Статус = Принтер.StopPrint();
```

### ClearBuffer() → Число
Очистка буфера очереди печати.
```bsl
Статус = Принтер.ClearBuffer();
```

### SendField(НомерПоля, Значение) → Число
Отправка данных в поле для печати.
```bsl
// Отправить КИЗ в поле 1
КИЗ = "(01)0880999084565666771(21)5/56BK(91)EE12(92)KZEB9/4566...";
Статус = Принтер.SendField(1, КИЗ);
Если Статус = 0 Тогда
    Сообщить("Данные переданы успешно");
ИначеЕсли Статус = 1 Тогда
    Сообщить("Ошибка принтера");
ИначеЕсли Статус = 18 Тогда
    Сообщить("Ошибка DPI — настройте принтер");
КонецЕсли;
```

### GetLastError() → Строка
Описание последней ошибки.
```bsl
Сообщить(Принтер.GetLastError());
```

## Коды P_Status

| Код | Описание |
|-----|----------|
| 0x00 | Успешно |
| 0x01 | Ошибка принтера |
| 0x12 | Печать не запущена |
| 0x42 | Буфер заполнен |
| -1   | Ошибка соединения/таймаут |

## Полный пример — печать КИЗ

```bsl
Процедура ОтправитьНаПечать(КодМаркировки)
    
    // Подключение
    Если Не Принтер.IsConnected() Тогда
        Если Не Принтер.Connect("10.10.0.2", 8010) Тогда
            Сообщить("Нет связи с принтером: " + Принтер.GetLastError());
            Возврат;
        КонецЕсли;
    КонецЕсли;
    
    // Запуск печати (если не запущена)
    Статус = Принтер.StartPrint();
    Если Статус <> 0 И Статус <> 17 Тогда // 17 = уже запущена
        Сообщить("Ошибка запуска печати: " + Статус);
        Возврат;
    КонецЕсли;
    
    // Отправка данных в поле 1
    Статус = Принтер.SendField(1, КодМаркировки);
    Если Статус <> 0 Тогда
        Сообщить("Ошибка передачи данных: " + Статус + 
                 " | " + Принтер.GetLastError());
    КонецЕсли;
    
КонецПроцедуры
```
